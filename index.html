How to Use Demo on Your Website

ZERO CONFIG

The Easiest Way: 1 Script Tag + 1 HTML Attribute

Users don't need to install Three.js or write any JavaScript. They simply add one script tag (hosted for free on GitHub via jsDelivr) and put data-synaptic-bg on their section:

<!-- 1. Include the library in <head> (Free CDN from GitHub) -->
<script src="https://cdn.jsdelivr.net/gh/ideepakmathur/synaptic-net@main/synaptic-net.min.js"></script>

<!-- 2. Add data-synaptic-bg to ANY container on the website -->
<section class="my-hero" data-synaptic-bg="ripple-net">
  <div style="position: relative; z-index: 2;">
    <h1>Your Website Title</h1>
    <p>Three.js starts automatically and adapts to container size!</p>
  </div>
</section>

  border-radius: 16px;
}

STEP 1

Add Three.js & Script to Your Page

Include Three.js via an import map and copy the demo engine module into your project:

<script type="importmap">
{
  "imports": {
    "three": "https://unpkg.com/three@0.160.0/build/three.module.js"
  }
}
</script>
<script type="module" src="./demos-engine.js"></script>
STEP 2

HTML & CSS for Your Target Section

Any container on your website can host this background (100% full-width hero, card, or banner). Simply add position: relative and overflow: hidden:

<!-- Target Section on your website -->
<section class="my-interactive-section">
  <!-- Canvas will sit behind content -->
  <canvas class="bg-canvas"></canvas>

  <!-- Your HTML text, buttons, or cards -->
  <div class="content">
    <h1>Your Title Here</h1>
    <p>Interactive, responsive Three.js background.</p>
  </div>
</section>

<style>
.my-interactive-section {
  position: relative; /* Essential: keeps canvas inside */
  overflow: hidden;
  width: 100%;        /* Or any custom size: 800px, 50vw, etc. */
  min-height: 480px;
  background: linear-gradient(135deg, #2a42f7 0%, #0a1128 100%);
  border-radius: 16px;
}

.my-interactive-section .bg-canvas {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  z-index: 1;         /* Sits above background gradient */
  pointer-events: none; /* Allows cursor hover to pass through smoothly */
}

.my-interactive-section .content {
  position: relative;
  z-index: 2;         /* Content stays above canvas */
}
</style>
STEP 3

Initialize in JavaScript

// Import the active demo function
import { createDemo5 } from './demos-engine.js';

const container = document.querySelector('.my-interactive-section');
const canvas = container.querySelector('.bg-canvas');

// Initialize! Automatically attaches resize listeners
const effect = createDemo5(canvas, container);

// ResizeObserver adapts the canvas whenever your container changes size:
const observer = new ResizeObserver(() => {
  effect.resize(container.clientWidth, container.clientHeight);
});
observer.observe(container);
REACT COMPONENT

Plug-and-Play React / Next.js Component

Drop this component directly into any Next.js or React page:

import React, { useEffect, useRef } from 'react';
import { createDemo5 } from './demos-engine.js';

export function InteractiveHero() {
  const containerRef = useRef(null);
  const canvasRef = useRef(null);

  useEffect(() => {
    if (!containerRef.current || !canvasRef.current) return;

    const effect = createDemo5(canvasRef.current, containerRef.current);

    const observer = new ResizeObserver(() => {
      effect.resize(containerRef.current.clientWidth, containerRef.current.clientHeight);
    });
    observer.observe(containerRef.current);

    return () => {
      observer.disconnect();
      effect.destroy();
    };
  }, []);

  return (
    <section 
      ref={containerRef} 
      style={{
        position: 'relative',
        overflow: 'hidden',
        width: '100%',
        minHeight: '480px',
        background: 'linear-gradient(135deg, #2a42f7 0%, #0a1128 100%)',
        borderRadius: '16px'
      }}
    >
      <canvas 
        ref={canvasRef} 
        style={{ position: 'absolute', top: 0, left: 0, width: '100%', height: '100%', zIndex: 1, pointerEvents: 'none' }} 
      />
      <div style={{ position: 'relative', zIndex: 2, padding: '40px 24px', textAlign: 'center' }}>
        <h1>Your Website Title</h1>
        <p>Interactive responsive background</p>
      </div>
    </section>
  );
}
